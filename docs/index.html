Gravação Escolha um método — o Rescue Mode é o mais simples e seguro.

  1. Configure o IP do PC
    Placa de rede com 192.168.0.2, máscara 255.255.255.0, gateway 192.168.0.1. Cabo na LAN 1.
  2. Desligue o roteador (retire da tomada).
  3. Entre no Rescue Mode
    Mantenha o botão WPS pressionado, ligue o roteador e continue segurando por 20 segundos.
  4. Abra a página de recuperação
    http://192.168.0.1
  5. Envie o arquivo
    Selecione recovery_bundle.bin e clique em Upgrade. Aguarde o roteador reiniciar sozinho (3–5 min).
  6. Pronto! Siga o Pós-flash.
ℹ️A tela de Rescue valida o cabeçalho TP-Link do arquivo. Use exatamente o recovery_bundle.bin deste repositório (não o FIT “cru”).

Para quem já tem SSH no roteador (firmware customizado anterior). IP padrão: 192.168.0.1.

  1. Envie o arquivo para a RAM (Dropbear não tem SFTP, use -O) 
    scp -O recovery_bundle.bin root@192.168.0.1:/tmp/
  2. Aplique o padding de 512 bytes e grave 
    ssh root@192.168.0.1
dd if=/dev/zero of=/tmp/pad.bin bs=512 count=1 2>/dev/null
cat /tmp/pad.bin /tmp/recovery_bundle.bin > /tmp/flash_bundle.bin
rm -f /tmp/pad.bin
FILESIZE=$(ls -l /tmp/flash_bundle.bin | awk '{print $5}')
/sbin/bcm_flasher /tmp/flash_bundle.bin $FILESIZE 512
    Aguarde Image flash complete, you may reboot the board.
  3. Reinicie 
    reboot

Método avançado via console serial (UART 115200 8N1) e servidor TFTP — grava apenas o rootfs, a partir do arquivo rootfs1_mod.bin gerado com build_rootfs.sh.

  1. No PC, IP 192.168.12.2 na porta WAN/2.5G e inicie o TFTP: 
    python serve_tftp.py
  2. Interrompa o autoboot do U-Boot (qualquer tecla) e execute: 
    setenv ipaddr 192.168.12.1; setenv serverip 192.168.12.2; setenv netmask 255.255.255.0
ping 192.168.12.2
ubi part image
tftpboot 0x05000000 rootfs1_mod.bin
ubi write 0x05000000 rootfs1 <TAMANHO_HEX>
setenv bootcmd "test_mode enable; sdk boot_img"
saveenv
reset
ℹ️O <TAMANHO_HEX> é impresso ao final do build_rootfs.sh. Veja o guia de partições Dual-Bank para o modo expandido (~66 MB).

Pós-flash Primeiro acesso e conexão ao seu controlador.

  1. Acesse a WebUI em http://192.168.0.1 ou SSH: 
    ssh root@192.168.0.1     # senha padrão: changeme
  2. Troque a senha de root 
    passwd
  3. (Opcional) Adicione sua chave SSH 
    echo "ssh-ed25519 AAAA... voce@pc" >> /etc/dropbear/authorized_keys
  4. Aponte para o seu Floresta Cloud Controller 
    set-inform https://<SEU_CONTROLADOR>/ws/router
    ou manualmente: 
    uci set floresta_cloud.global.server_url="https://<SEU_CONTROLADOR>/ws/router"
uci commit floresta_cloud
/etc/init.d/floresta_agent restart
✅O agente restaura automaticamente configurações salvas em /data após um factory reset. A versão é fixada em 77.0.1 e o OTA oficial da TP-Link é bloqueado.

SintomaCausa / solução

Rescue recusa o arquivoArquivo corrompido ou errado. Baixe novamente e confira o SHA-256; use o arquivo com cabeçalho TP-Link.
Reboot em loop após gravarReentre no Rescue Mode e grave novamente.
size > volume size! Aborting! (U-Boot)O rootfs excede a partição (33,1 MB). Use o modo expandido ou reduza o conteúdo.
