Upgrade de Firmware e RootFS via SSH com /sbin/bcm_flasher

Atualize o roteador remotamente via SSH sem precisar de botão WPS ou cabo serial.

1. Por que /sbin/sysupgrade falha e /sbin/bcm_flasher funciona?

A WebUI oficial e o /sbin/sysupgrade invocam /usr/bin/nvrammanager, que exige assinatura RSA-2048 PSS da TP-Link. Já o utilitário nativo do SDK Broadcom (/sbin/bcm_flasher):

  • Não depende da checagem RSA proprietária da TP-Link.
  • Reconhece pacotes FIT padrão Broadcom (conf_6764_nand_squashfs / recovery_bundle_raw_fit.bin).
  • Grava automaticamente Kernel e RootFS no slot inativo e atualiza metadata1/metadata2 (COMMITTED + incremento de SEQ).

2. A Descoberta Crítica: O Gotcha do upfileoffset == 0

Se você chamar /sbin/bcm_flasher arquivo.bin $FILESIZE 0, ele aborta imediatamente:

Flash image filesize = 36547576, upfileoffset = 0. Error: Aborting

A análise assembly ARM da função main revelou que a Broadcom codificou a trava porque o utilitário foi feito para ler arquivos temporários de upload CGI multipart (onde o firmware começa após os cabeçalhos HTTP):

0x00010a6c:  cmp   r7, #0          ; Compara upfileoffset com 0
0x00010a70:  cmpne sl, #0          ; Se upfileoffset != 0, compara filesize com 0
0x00010a74:  moveq fp, #1          ; Se algum for 0, marca erro e aborta!
...
0x00010b40:  bl fseek(fd, upfileoffset, SEEK_SET)
0x00010b38:  sub r3, filesize, upfileoffset
💡Solução: Prependemos um cabeçalho de 512 bytes de zeros (pad.bin) ao pacote FIT e passamos upfileoffset = 512. O bcm_flasher valida que upfileoffset != 0, faz fseek(512) e grava perfeitamente!

3. Procedimento Passo a Passo

  1. Envie o pacote FIT para a RAM do roteador (use -O pois o Dropbear não possui SFTP): 
    scp -O recovery_bundle_raw_fit.bin root@192.168.0.1:/tmp/recovery_bundle.bin
  2. Aplique o padding de 512 bytes e execute o bcm_flasher: 
    ssh root@192.168.0.1

dd if=/dev/zero of=/tmp/pad.bin bs=512 count=1 2>/dev/null
cat /tmp/pad.bin /tmp/recovery_bundle.bin > /tmp/flash_bundle.bin
rm -f /tmp/pad.bin /tmp/recovery_bundle.bin

FILESIZE=$(ls -l /tmp/flash_bundle.bin | awk '{print $5}')
/sbin/bcm_flasher /tmp/flash_bundle.bin $FILESIZE 512
  3. Verifique a mensagem de conclusão e reinicie: 
    # Saída esperada:
# Image flash complete, you may reboot the board
# Image change to another new state
reboot
  4. Confirme a troca de slot após o boot: 
    mount | grep ' / '
