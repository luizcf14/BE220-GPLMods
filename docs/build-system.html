Pipeline de reconstrução do SquashFS, empacotamento FIT e árvore GPL OpenWrt/BCM6764.

1. Modificação do RootFS (build_rootfs.sh)

O script build_rootfs.sh reconstrói o SquashFS de forma determinística dentro de uma pasta temporária ext4 no WSL2:

  • Extração Segura: Descompacta mtd8_rootfs1.bin em /tmp/be220_squashfs_work preservando todos os symlinks e dispositivos.
  • Patches de Acesso: Configura /etc/inittab, /etc/passwd, /etc/shadow e o boot hook /etc/rc.d/S99zzzzboot_done (Dropbear -L e devpts).
  • Proteção de Config no 1º Boot (loadconfig): Salva cópias imutáveis em /etc/captiveportal/captiveportal.default e floresta_cloud.default para sobreviver à limpeza que o /sbin/loadconfig faz em /etc/config durante o S10boot.
  • Bloqueio de OTA Oficial: Fixa a versão em 77.0.1 Build 20991231 rel.99999 em /etc/partition_config/soft-version e bloqueia ota-download.tplinkcloud.com em /etc/hosts.
  • Reempacotamento XZ: Gera rootfs1_mod.bin com mksquashfs -comp xz -b 1048576 -noappend -root-owned.
# Modo genérico (sem chave SSH pessoal, senha padrão 'changeme'):
wsl -d Ubuntu-24.04 bash build_rootfs.sh 1

2. Empacotamento do Recovery Bundle (generate_recovery_bundle.sh)

Combina mtd1_loader.bin, mtd7_bootfs1.bin e rootfs1_mod.bin usando o Device Tree template firmware.its e o utilitário mkimage:

  • Gera recovery_bundle_raw_fit.bin (imagem FIT pura com magic 0xd00dfeed).
  • Anexa o cabeçalho TP-Link (0x1014 bytes + partição fwup-ptn com support-list e soft-version + hash MD5 com salt) produzindo recovery_bundle.bin.
wsl -d Ubuntu-24.04 bash generate_recovery_bundle.sh

3. Infraestrutura OpenWrt & Broadcom BCA (GPL)

O código-fonte GPL da TP-Link combina duas árvores principais para os modelos BE220, BE230, BE3500 e BE3600 Pro:

Iplatform/ — Camada OpenWrt e Pacotes

  • openwrt/: Regras de build, sistema UCI, LuCI e infraestrutura de pacotes (opkg).
  • packages/: Daemons e bibliotecas do espaço de usuário (Dropbear customizado, uhttpd, utilitários TP-Link).
  • build/product_configs/: Perfis de compilação por modelo de hardware.

bcm504L04/ — SDK Broadcom BCM6764

  • Kernel Linux 4.19 customizado para ARMv7 quad-core Broadcom BCA.
  • Drivers proprietários de Wi-Fi 7 (802.11be), MLO, switch Ethernet (ethswctl, ethctl) e aceleradores de pacotes (Flow Cache / BLOG).
  • Bootloader U-Boot 2019.07 (BTRM → SPL → TPL → U-Boot) e ferramentas de imagem FIT.
